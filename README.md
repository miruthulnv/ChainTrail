# ChainTrail - Hash-Chained Audit Log

This repository implements a lightweight, append-only, tamper-evident audit log in Python using only the standard library.

The core implementation, demo, and test suite are located in the [`audit_log/`](file:///Users/miruthulnv/ChainTrail/audit_log) directory.

### Quick Start

```bash
cd audit_log
python demo.py
python test_audit_log.py
```

See [audit_log/README.md](file:///Users/miruthulnv/ChainTrail/audit_log/README.md) for full architecture, design documentation, and details on cryptographic checks.
